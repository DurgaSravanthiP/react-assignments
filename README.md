# React assignments

This repository contains small React projects built as part of frontend
assignments.

## Team chat

The [chat app](./chat-app) is a single-page team messaging interface. Messages
are assigned a random name from the assignment's user list, and each message
has its own like counter.

### Run locally

```sh
cd chat-app
npm install
npm run dev
```

Open the local URL printed by Vite. Press **Enter** to send a message or
**Shift + Enter** to add a line break.
